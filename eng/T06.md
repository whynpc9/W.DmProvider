# T06 transport acceptance commands

`eng/t06.sh offline` runs the deterministic transport/frame/deadline suite, builds the real probe, and runs `eng/t05.sh offline` as a session-ownership regression. Both test suites require strict TRX validation: every case passed and executed; all skipped, failed, aborted, pending, and other nonpass counters must be zero. A successful offline run reports `integration_pending`.

`eng/t06.sh real` builds `TransportProbe` and invokes it through `scripts/with-dameng-test.sh` only, then runs `eng/t05.sh real` as a session-ownership regression. The probe must select `PlaintextAllowed` through the typed W builder, verify the server account and schema as `WDM_PROVIDER_TEST`, create a unique table only in that schema, independently read back inserted data, and drop the table in `finally` with a fresh connection proving its absence. It records a successful Open TCP connection count with no credential or packet payload. It records only numeric opcodes from a successful Open, then injects local faults after the observed STARTUP, LOGIN, and first schema initialization frames are encoded and before each target frame is sent. Each fault checks Closed state, single socket disposal, and a fresh successful Open. Real results are W only; official and restored results are never inferred from them.

Both modes create a fresh ignored `.local/t06/runs/<id>` directory, set writable `DOTNET_CLI_HOME`, disable first-run behavior and telemetry, and use one MSBuild node with node reuse and shared compilation disabled. Failure emits only a structured stage and exit code. The real probe suppresses raw exception text, credentials, and stderr. Preserve failed run records rather than counting partial runs as passes.

NET-01 to NET-04 belong to T06. NET-05 (async-only fake stream), TLS-01 to TLS-03, and NAT-01 are later task gates. The test vectors reference the verified 64-byte header, little-endian command at offset 4, signed body length at offset 6, and checksum/CRC paths in `src/W.DmProvider/Internal/Legacy/A/T02_02000092.cs` and `src/W.DmProvider/Internal/Legacy/Dm/T02_0200008D.cs`. No fake peer should claim to implement undocumented Dameng responses.
