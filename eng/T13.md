# T13 runner

此入口消费已经冻结的唯一版本实际包；产品源码打包和 AsyncTests 由独立 Low 验证负责人安排，其他 agent 不运行 dotnet 或实库。

```sh
eng/t13.sh offline <exact-version> <absolute-local-package-source>
eng/t13.sh shared <exact-version> <absolute-local-package-source>
eng/t13.sh tls <exact-version> <absolute-local-package-source>
eng/t13.sh security-shared <exact-version> <absolute-local-package-source>
eng/t13.sh security-tls <exact-version> <absolute-local-package-source>
```

如需指定已安装 SDK 命令，可设置 `DOTNET_COMMAND=/absolute/path/to/dotnet`；仓库 `global.json` 的 pinned SDK 规则仍有效。runner 先设置可写 cli-home、禁用首启和 telemetry，build 使用单节点/noReuse/noSharedCompilation/disable-build-servers；不清理全局 NuGet cache，使用独立 cache 与 bin/obj。

每轮新的 `.local/verification/r2/t13/runs/...` 保留 package manifest、consumer build log、safe probe JSON、独立 envelope 校验。运行前后 nupkg SHA 必须不变；loaded DLL SHA 必须匹配包内 net10 asset。offline 只通过包身份和 26 项公开异步 override 检查，明确 `integration_pending`。真实 TEST/shared 或独立 TLS 运行必须全部 13 项 case、Read 阶段 Fetch、真实 NextResult、LOB 网络帧、事务新连接行结果和 cleanup absence 通过。保存点的 `8.1.5.60` profile 保持完整成功断言；独立 TLS `8.1.4.6` profile 必须通过三项精确无 I/O 拒绝、事务/连接存活及整事务回滚的严格检查，报告 `unsupported_for_server_profile`，不得标保存点成功或 skip。其他 profile、任何缺失或无连接均不得当 real pass。

当前工具源码尚未由独立 Low 编译/实库执行；本文描述执行方式与预期断言，不代表已验收。

Probe 详见 [R2AsyncProbe](../tools/R2AsyncProbe/README.md)。T14 取消/期限验收随后独立推进；本入口不以真实包 smoke 替代 async-only barrier 单元测试和完整调用链 review。

`security-shared` 与 `security-tls` 使用同一精确包分别执行安全拒绝验收，输出独立 JSON 与 validator 分支，不重新执行 13 项正向 case。前后新有效 TEST 连接校验身份、Schema、实际 STARTUP 模式和 LOGIN hook 正控制；负向连接必须关闭、仅编码 STARTUP、LOGIN 编码次数 0、单 socket 已释放且无成功 TLS 升级。共享明文的 RequireTls 必须精确 NotSupported；独立 mode 1 与无关 CA 必须精确 AuthenticationException。服务器模式、实例及系统信任库不变；无关 CA 仅内存生成后写公开 PEM 到 0700 目录/0600 文件并 finally 删除，绝不导出私钥。
