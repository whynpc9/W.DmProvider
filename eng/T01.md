# T01 local commands

The root `global.json` pins SDK 10.0.203. `eng/t01.sh` sets a writable CLI home,
turns off first-run and telemetry, uses single-node builds, and places the
official package restore cache under ignored `.local/t01/` with `packages/` as
the only restore source. For capture, verify, offline, and official actions,
build diagnostics go to stderr so stdout contains only one JSON document.

```sh
eng/t01.sh build
eng/t01.sh verify
eng/t01.sh offline
eng/t01.sh official
```

`official` loads only the test credential through `scripts/with-dameng-test.sh`.
It opens a connection, verifies the server login, runs only read-only SQL, and
closes it. Results are first saved under ignored `.local/t01/` and then shown.
The fixture values are bound as parameters. No credential or raw
exception text is emitted. If the fixture round trip differs, the command exits
nonzero and retains the observed hashes in JSON.

To verify rejection without changing source, copy `packages/`, `decompiled/`
and `upstream/` into a temporary directory, then run
`eng/t01.sh verify <copy-root>`. The second optional argument selects a
manifest in another path. Adding, removing, or changing a file under either
source tree rejects the copy.

`eng/probe-scenarios.json` lists the complete S01 O/R/W scenario set. Only O
Open/Close and parameter SELECT are implemented in this minimal host. R and W
remain pending, and this host says nothing about the downstream EF consumer.
