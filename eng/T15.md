# T15 runner

消费已经冻结、唯一精确版本的本地 nupkg；只允许独立 Low 验证负责人执行。产品源码打包另由验证窗口安排，本 runner 不重建产品。

```sh
eng/t15.sh offline <exact-version> <absolute-frozen-local-feed>
eng/t15.sh shared <exact-version> <absolute-frozen-local-feed>
eng/t15.sh tls <exact-version> <absolute-frozen-local-feed>
```

可设置 `DOTNET_COMMAND=/usr/local/share/dotnet/dotnet` 使用仓库 pinned SDK 10.0.203。构建前设置独立可写 DOTNET_CLI_HOME、禁用首启与 telemetry；单节点/noReuse/noSharedCompilation/disable-build-servers。不改 global.json，不清理全局 NuGet cache。

每轮 `.local/verification/r3/t15/runs/...` 保存安全 `commands.json`（命令与实际退出码）、前后 package manifest、隔离 consumer build log、case checkpoint、probe stdout、独立 validator 结果。只有包前后 hash 不变、加载 DLL hash 相同、实际必需 case 与精确 own-object fresh 清理全部成功才通过。真实连接凭据仅由相应 TEST wrapper 注入 runtime，不进入 build/命令参数/制品。

默认安全结论为 VerifiedResetOrDiscard 的 discard 分支：`SessionReset` 未证明，不能把 SELECT 1/ROLLBACK/SET SCHEMA 当全量 reset，未探测状态不能称受支持。offline 成功仍是 integration_pending；shared/tls 是两个独立 server profile，必须分别报告实际结果。任一必需 case/清理失败必须非零。无法连接不是实库成功。完整说明见 [R3ResetProbe](../tools/R3ResetProbe/README.md)。

外部 runtime 最长 900 秒，timeout JSON 和最新 checkpoint 必须保留并标未验收；由 TEST 身份的独立验证者按 checkpoint 的本轮唯一名字进行精确恢复，记录服务器最终状态。没有 runtime log/raw exception 输出。

本轮源码准备完成后等待 root review/冻结，由独立 Low 编译与实库执行；未执行前不宣称 T15 已通过。
