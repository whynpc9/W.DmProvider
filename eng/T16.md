# T16 runner

由独立 Low 验证负责人消费已冻结的唯一精确 nupkg，runner 不重建产品。

```sh
eng/t16.sh offline <exact-version> <absolute-frozen-local-feed>
eng/t16.sh tls <exact-version> <absolute-frozen-local-feed>
eng/t16.sh shared <exact-version> <absolute-frozen-local-feed>
```

可用 `DOTNET_COMMAND=/usr/local/share/dotnet/dotnet` 选择 pinned 10.0.203。独立 CLI home、禁用首启/telemetry、单节点/noReuse/noSharedCompilation/disable-build-servers，独立包 cache，不清空全局 cache。

每轮 `.local/verification/r3/t16/runs/` 保存命令及实际退出码、前后包 hash、consumer source manifest、独立 consumer、checkpoint、runtime 安全 JSON 和 validator。consumer source manifest 仅记录工具输入哈希与观察到的 Git HEAD；产品来源仍由 root 冻结 candidate manifest 对应，不宣称 SourceLink。构建无 secret；runtime 由 TEST/TLS wrapper 注入凭据。任一必需场景、最终计数或精确 own-object 清理失败即非零并停止；失败结果不改写。900 秒进程护栏超时后由 Low 按 checkpoint 唯一对象进行精确恢复，记录最终服务器状态。

TLS 验证显式证书的 DataSource 独立容量域，direct 显式证书池化保守拒绝；shared 额外验证同 key registry 容量。真实新登录、全部返回销毁、等待取消/截止、Clear/Dispose、快捷 command/reader 和旧对象边界见 [R3PoolProbe](../tools/R3PoolProbe/README.md)。offline 不声明实库通过，真实 profile 分别记录；没有 reset/reuse/握手性能结论。准备状态需 root 冻结后才由 Low 执行。
