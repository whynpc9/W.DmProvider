## 本轮交付

1. 可重跑的来源采集与校验工具，生成官方 nupkg、net9.0 DLL 的真实 SHA-256、MVID、程序集版本、TFM、卫星资源和来源快照逐文件清单。记录采集工具与本次运行的 SDK/Runtime；历史反编译工具版本无证据时保留 null 和原因。
2. 保留现有 `packages/` 和 `decompiled/` 作为原始来源，不移动、不覆盖、不重新反编译。`upstream/DM.DmProvider/8.3.1.47463/` 存放来源清单并引用现有路径；逐文件校验承担快照变更检测。恢复源码映射由 T02 产生，不能预填已恢复记录。
3. 官方 O 使用独立的 net10.0 探测宿主，以本地固定 NuGet 包解析实际 compile/runtime 资产并核对实际加载 DLL 的哈希/MVID。该结果证明这个宿主的资产选择；不得冒充下游 EF 的实跑证据。R/W 仅登记 pending，不在同一进程装载，不生成可调用的伪实现。
4. O/R/W 场景目录列出 S01 要求的范围和各实现状态。本轮只运行 O 的 Open/Close、参数 SELECT 与只读服务器环境采集；完整 CRUD、事务、LOB、恢复差分属于后续任务，必须显式 pending。
5. 固定官方源资产的机器可读结果可以入库。真实实例运行结果先写 `.local/`；可入库报告只保留版本、平台、结果与匿名实例标识，不保存地址、账号、连接串、口令、原始认证报文或秘密的稳定散列。配置标识使用随机运行标识；异常仅输出类型和代码。
