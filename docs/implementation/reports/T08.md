## 实现与审阅修正

- CommandPlan 冻结 SQL、参数 metadata/值和期限；Command、Parameter、Collection 共用修改门。Reader 持有计划到 Close；byte[]/char[] 复制，Clone 独立父关系。公开重命名入口不能用伪造旧名破坏索引。
- ResultCursor 区分可读 rowset、已知 DML 计数及精确终结响应。空 rowset 保留，切换结果刷新列、getter 和缓存；不把 ret162 复合结果的行数冒充影响数。未知 aggregate 为 -1，显式 SQL%ROWCOUNT 独立保留，溢出抛异常。
- NonQuery 完成结果遍历；Scalar 保留首个结果的空集/DBNull 语义。标志逐位处理，SchemaOnly/KeyInfo 提前拒绝。GetSchemaTable 仅使用本地 metadata，未知键属性为 DBNull。
- Reader/已准备 Command 的正常关闭使用独立有限 CleanupTimeout。无法安全恢复的失败路径中止捕获的会话；清理不覆盖原始读取异常。Command.Dispose 不提前释放活动 Reader。
- 删除参数编码失败后的逐元素数组执行补救，以及 Prepare 失败后发送空 SQL 的隐藏路径。复杂类型、输出参数和未验证能力继续明确拒绝。
