## 实现与公开契约

Session/Lease/Invocation/Transport 以同一身份协调器原子处理发送尝试、首个终止原因和完成；注册/释放callback与实际abort在锁外。Command plan保存捕获lease和sticky取消请求，覆盖lease发布前竞态；无活跃Cancel为no-op，陈旧身份不能关闭新会话。

预发送取消/超时保留原会话、Active事务、prepared handle和metadata；发送后AbortPhysicalSession/Broken，不重连或重放。Reader返回后旧Execute token解绑，后续Read使用新token。每public调用冻结deadline，内部分块/Fetch/heartbeat共享；cleanup独立有限None预算。长期限分段timer、亚毫秒向上取整及状态完成竞态有虚拟时钟测试。

新增getter-only安全FailureInfo、DmTimeoutException、DmOperationCanceledException；本地符号/服务端Number分离，用户取消保留原token。Sent Commit失确认顶层固定OutcomeUnknown/WDM_COMMIT_UNKNOWN，优先于取消/超时；完整验证ACK固化Committed。预发送异常返回的事务metadata随EndControl恢复Active，与实际状态一致。详见 [R2边界](../../compatibility/R2.md) 和 [设计](../T14-design.md)。

改动位于PublicApi Connection/Command/Reader/Transaction、Sessions/Execution/Transport、协议Async续接及数字观测hook；来源快照/官方资产只读。参数化执行、多结果、精度、保存点、TLS和64MiB物化边界保留。
