# T09 参数绑定与类型精度

日期：2026-09-30。状态：**integration_verified，T09 完成**。主 agent 负责设计和审阅；最终修复由 GPT-6.1 Sol High 执行，GPT-6.1 Sol Low 独立验证。原始合成向量由 Luna Max 准备，未将向量的 `not_run` 状态冒充实测。

## 实现

- 显式 provider type、DbType、可靠 describe 与 CLR 推断分开记录。服务端 flag 2 仅作建议，不覆盖 CLR/显式类型；无类型 NULL 若只有建议描述则拒绝，显式类型或可靠列描述可以绑定 NULL。ResetDbType 恢复推断，Prepare 类型/大小变化重新准备。
- 参数按词法标记绑定，字符串和注释不参与，重复命名标记复用同一冻结值，归一重名及命名/位置混用拒绝。显式 unsigned 类型即使采用较宽 wire 表示，仍验证原始声明范围。
- 新增不可变 `W.Dm.DmDecimal`（BigInteger coefficient/scale）。CType 9 使用精确 base100，CType 24 使用固定 Int64 加 scale；普通 decimal 无法精确表示时抛 OverflowException，provider-specific getter 保留精确值。不通过 double 编码 decimal。
- resolved CType 一直保留到最终参数编码，修复 UInt64 被降为 Int64、DateOnly/TimeOnly 被改成 TIMESTAMP、INTERVAL 限定丢失等路径。默认 INTERVAL 使用已验证的 DAY(9) TO SECOND(6)，显式 Scale 不覆盖 subtype/leading 位域。
- 普通 CHAR/VARCHAR(36) 保持 string；显式 Guid getter 和真正 CLR Guid 输入有受控字符/16 字节约定。二进制超容量明确失败，通用 Binary 参数使用 VARBINARY，固定 BINARY 需要有效容量；空 byte[] 与 NULL 分开。
- 严格字符编解码拒绝非法代理项/坏字节。时间不丢可表示 ticks/offset；低 scale INTERVAL 格式保留小数前导零，原 EF GetString 解析形态保持。泛型数值 getter 不经 Convert.ChangeType 舍入，typed NULL 不再变成空字符串。
