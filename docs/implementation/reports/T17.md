## 行为与兼容边界

`DmDataReader.GetStream/GetTextReader` 惰性提供 forward-only 流，不在创建时读取字段。每 reader 至多一个活跃字段流，绑定行、session/generation/execution、事务；前进行/结果、父关闭、事务结束使旧流在 I/O 前失效。SequentialAccess 位置单调，关闭再开不能绕过已消费位置；CLOB 编码字节与 UTF-16 消费单位不能混用。

BLOB `GetBytes` 有界读取与跳过，已知验证长度无需 GETLEN；CLOB `GetChars` 使用 CLR UTF-16 偏移，从深拷贝 locator 自零有界扫描，空 destination 的长度查询独立于主位置。wire offset 仅遵循实际 Data.len，不能把 opaque server units 当 bytes、runes 或 UTF-16。strict stateful decoder 保留跨帧编码状态，最终 flush；响应长度/更新 locator 在 payload allocation 前验证，短读、截断、无进展均不补零或伪装 EOF。

保留旧 CLOB `GetBytes` 的全量编码字节兼容路径，仍受 64 MiB 返回 payload cap；它不是 CLOB 流式入口。真正全量 `GetValue/GetFieldValue/GetString/loadAllData` 的 cap 保持。旧 getter NULL6081、顺序6097、既有参数边界异常保持。范围/长度扫描从旧 cap 限制迁移的断言，均由独立 metadata/真实帧/UTF-16 oracle 代替；旧预载缓存配空 locator 的夹具改为合法 inline wire，不恢复产品缓存旁路。

输入 `Value=Stream/TextReader` 必须显式 `DmSqlType=Blob/Clob`、Input direction。计划冻结调用者引用及类型，同一对象多 marker occurrence 在读取前拒绝。未知长度、不可 seek、短正读均支持；async 只调用 Memory ReadAsync。调用者始终拥有输入，不读 Length/Position、不 Seek/Dispose/rewind/replay。重复执行读取当前位置。实际 modern PUT_DATA2 opcode26，完整 ACK opcode261/status0/21-byte opaque token，逐次传最新 token，初始 sentinel 来源固定、失败 closed。空输入、整块尾空帧和末短帧均有独立 oracle。
