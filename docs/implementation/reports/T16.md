## 行为与边界

增加 DmDataSource / 工厂入口、不可变私有配置、独立owner、快捷command/reader；直接连接显式Pooling=true使用完整配置相等的有界registry。Pooling默认false，MaxPoolSize默认100、MaxPoolWaiters默认1024，PoolAcquireTimeout为一次绝对预算，等待与建连不续期。creating/leased/closing均占容量，物理中止完成后恰好释放。Clear增长同owner epoch、不分裂容量或打断业务；Dispose结束新入场与等待，已借出业务可以完成。新SessionId、pending generation与捕获执行身份共同保护旧对象/回调。

registry最大128项，真正零借出/创建/关闭/等待/引用后120秒空闲回收，访问驱动，无每连接后台线程。配置键完整相等，哈希碰撞不共池，ToString隐藏秘密。显式证书文件的直接Pooling=true在socket前明确拒绝；使用独立DmDataSource，默认system-trust TLS无显式文件仍可registry。证书文件不是不可变字节快照，轮换后重建DataSource。旧legacy pool/statement cache未启用。

DataSource快捷命令非reader成功/失败归还，reader持有连接到Close/Dispose；参数跨执行保留，async真实网络路径无同步fallback，Dispose/创建/reader发布线性化且清理异常不覆盖主typed失败。

实库发现的错误分类修复：sync/async execute/prepare共享四个有界严格字符串与完整body校验，同一session gate原子接受当前wire/调用的receipt与取消/期限首因。ServerReported与“可保留session”独立；generic错误仍Broken/discard、事务保守Unknown、真实Number保留，不建议重试。原8.1.5.60/-2106/同ActiveTX恢复白名单未扩大；prepare不增恢复。非法编码、长度、trailing、所有权错误和取消/期限先获胜不提升ServerReported。

另移除同步C2p优化网络调用失败后的透明重放（reader及当前internalNonQuery可达两处）；本地parser回退和成功优化路径保留。未知发送错误保持原异常、Unknown与不重放，物理关闭后归还容量。
