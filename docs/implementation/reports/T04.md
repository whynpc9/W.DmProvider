## 行为变更

- Builder 的字符串、别名和 typed 属性经过明确验证；连接获得不可变 settings snapshot，旧协议层使用独立副本。停止环境服务文件读取、含密码配置的稳定 hash，以及连接级配置改写进程全局状态。
- Host/User/Password 无默认值；命令默认 30 秒，显式 0 保留。旧连接串及 Builder 的 connect/pool/socket 整数超时仍为毫秒；标准 `DbConnection.ConnectionTimeout` 返回向上取整的秒。新增 TimeSpan 属性拒绝负值、溢出和非整数毫秒。
- 未知设置和不支持的非默认值明确拒绝。`InitialCatalog` 不再更改认证信息。限额类选项仅允许当前固定声明值，不声称后续收包或 LOB 限额已执行。
- 只有 Closed 可以替换配置；Opening 门闩覆盖 Connecting 通知、schema 初始化和失败清理。事件内改配置或重入 Open 被拒绝。
- `PersistSecurityInfo=false` 时在公开 Open 事件前隐藏口令，关闭和之后的失败重开也不恢复公开口令；Clone 继承脱敏状态，内部认证仍来自私有快照。
- 默认 RequireTls 在 socket 前拒绝，等待 T07 的真实 TLS 实现。授权测试须明确选择 PlaintextAllowed；TLS/原生加密协商模式在旧 cipher 初始化前拒绝，旧恒真证书回调不再可用。
- 池化、statement cache、重连、读写分离、Enlist、FLDR/Bulk/native、SkyWalking、服务文件及旧日志的未验收入口受到守卫。filterHead 不接受非空注入，共享链不构造；旧日志写路径和线程停用。原生 `DmFldrDllCall` 改为 internal。
- Schema 所有入口共享校验，非空值作为单个带双引号的标识符发送，内嵌双引号转义并保留大小写。128 个 .NET char 的限制是当前产品策略，不是 DM 服务端字节上限；空值清除，不发 SET。

详细选项和破坏性变更见 [T04-options.md](../../compatibility/T04-options.md)、[T04-breaking-changes.md](../../compatibility/T04-breaking-changes.md)。

## Builder 框架边界

实测 .NET 10 的 `DbConnectionStringBuilder.ConnectionString` setter 不是虚方法。自己的构造/字符串 setter 和连接字符串入口使用严格、事务性解析；基类 setter 仍有框架差异：

1. `ArgumentException` 及越界异常会被框架回滚到原有效配置；该旧状态可以继续消费。
2. `NotSupportedException` 不回滚，Builder 进入不可消费状态，直到 Clear 或成功的自身字符串整体赋值。
3. 基类可能在调用派生代码前丢弃无引号空值；只有自有解析器能严格保留并拒绝空数值。不能把上转型赋值描述为具有同样的原文保留能力。

为让所有收到的重复键经过验证，indexer 使用严格赋值：等价值可重复，换值应事先 Remove；typed 属性可以替换。已经失败的 indexer 不能通过事后 Remove 解锁，需 Clear 或整体重新赋值。测试和文档保留这些限制，不声称基类 setter 普遍原子。
