## Review 契约补充

SQL 参数和事务守卫使用 R1 已验收 profile 的非嵌套块注释语法；不会让第二个语句藏在深度计数内。整数 typed getter 对 SQL NULL 报转换错误，真实零值不变。CLOB null-buffer 长度探测返回 decoded UTF-16 长度且不消费顺序位置；R1 当前物化边界超过 int.MaxValue 明确拒绝。

Connection=null 清理本命令的连接及 statement 状态。活动执行/Reader、显式 active command.Transaction 或原物理会话正被其他 owner 使用时，连接变更快速失败并保留原绑定；调用方可先清 command.Transaction，事务对象仍由原连接管理。重新绑定后重新准备语句，不复用旧连接句柄。
