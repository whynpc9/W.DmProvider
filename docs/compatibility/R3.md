当前PR #2产品review定点修复待新候选独立验收；下表是已接受v6范围与历史结果，完整PR/merge尚未结束。

| 能力 | 当前范围 |
| --- | --- |
| DmDataSource / 直接 Pooling | 数据源独立容量 owner；直接池按完整配置/秘密隔离共享 bounded registry，默认 Pooling=false |
| 容量与等待 | MaxPoolSize 默认100，MaxPoolWaiters默认1024；creating/leased/closing占容量，FIFO等待和总 PoolAcquireTimeout |
| 物理复用 | reset未证实，所有归还会话销毁，实际复用率0；每租约重新认证，不宣称握手优化 |
| Clear / Dispose | 同容量域epoch退休；Clear不打断在借业务；Dispose终止新准入和等待者，在借业务可完成 |
| 显式TLS证书文件 | 直接DmConnection Pooling=true拒绝；使用独立DmDataSource。证书轮换后重建数据源，证书字节不宣称原子快照 |
| 输出LOB | lazy forward-only GetStream/GetTextReader；当前row/execution/transaction生命周期；单活动flow、顺序守卫 |
| 范围读取 | BLOB GetBytes有界；CLOB GetChars按CLR UTF-16扫描/偏移，wire Data.len保持opaque，不猜字符单位 |
| 输入LOB | 显式Blob Stream或Clob TextReader且Input；caller-owned未知长度/不可seek源，async分块，无重放/rewind/dispose |
| 完整物化 | 64MiB返回payload上限保留；CLOB GetBytes仍是编码字节完整物化兼容接口 |
| NCLOB / ROWID | 两已测profile的NCLOB折为TEXT/CLOB同servercodec，不宣称独立national codec；ROWID GetChars本地rendered，GetTextReader拒绝 |
| 诊断 | W.DmProvider ActivitySource/Meter；bounded后台export，固定enum/numeric标签；无SQL/values/credentials/baggage/traceState，累计计数独立于可丢队列 |
| 事务和故障 | 已确认提交/回滚诊断success；sent未确认OutcomeUnknown，不重试；一般服务器错误号保留但保守Broken，原精确-2106白名单不扩大 |
| 不支持 | statement pooling、未经验证的session reset、数组绑定/DbBatch（R4）、async connection GetSchema及未知native互操作 |
