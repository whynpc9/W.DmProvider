# R2 async preview 范围

T13–T14 限定 R2 async preview 已独立验收；尚未发行。实际状态以 [progress.json](../implementation/progress.json)、[T13](../implementation/reports/T13.md) 与 [T14](../implementation/reports/T14.md) 为准。来源为独立 W.DmProvider，net10.0，不依赖官方 DLL。

| 入口/边界 | R2 契约 |
| --- | --- |
| Open/Prepare/Execute/Read/NextResult | async 网络调用贯通，不使用 Task.Run 或基类同步 I/O fallback；缓存允许立即完成 |
| 本地事务/保存点/网络清理 | 异步协议与有限 cleanup；保存点仅 8.1.5.60，TLS 8.1.4.6 明确发送前拒绝 |
| BLOB/CLOB | R1 已有物化接异步长度/分块链，保留 64 MiB returned payload 上限；不是完整 streaming |
| token | 本次 invocation 生命周期；ExecuteReader 成功返回后旧 token 解绑，后续 Read 使用新 token |
| Command.Cancel | 当前冻结 execution/reader；inactive no-op，旧身份不能取消新执行 |
| Reader.IsClosed / Dispose | 会话失效可先返回IsClosed=true；仍需无条件Close/Dispose释放lease与command plan，之后命令设置才可修改 |
| 发送前取消/期限 | 零网络副作用，会话/Active 事务及既有 prepared handle 保留 |
| 发送后取消/期限 | AbortPhysicalSession，Broken，不透明重连、重放或回池；服务器是否已停止独立观察 |
| Commit 失确认 | OutcomeUnknown 优先，不建议自动重试；已完整验证的 ACK 固化终态 |
| deadline | Connect 总预算；每次 public Execute/Reader 调用一个冻结预算，内部 Fetch/chunk/heartbeat 不重置；cleanup 有限且独立 |
| metadata | Connection.GetSchemaAsync 明确 Unsupported；Reader.GetSchemaTableAsync 仅缓存 |
| 后续能力 | 池化、完整 streaming、复杂/cursor 参数、数组/DbBatch 未开放 |

最终候选通过575项离线、barrier/虚拟时钟、实际包双profile rowlock/final-state，以及同包T13双库业务和真实安全拒绝门。对应证据见T14报告。R1 hardened 同步链按 S08 例外保留；证书文件/原生 crypto 仍为既有初始化，异步网络路径另有测试。

| 本地符号 | 类型/公开分类 | 服务端 Number |
| --- | --- | --- |
| WDM_TIMEOUT | DmTimeoutException / Timeout，TotalDeadline 或 IdleTimeout | 0（没有伪造服务端错误） |
| WDM_CANCELED | DmOperationCanceledException / Canceled，保留原 token 与首 CancelSource | 不适用 |
| WDM_COMMIT_UNKNOWN | DmCommitOutcomeUnknownException / OutcomeUnknown，Commit/Unknown/不可复用；保留首 CancelSource 与 InnerException | 0 |

FailureInfo 只包含稳定分类、阶段、操作/事务结果、是否可复用及确实存在的服务器错误号，不含 SQL、连接串或认证报文。完整原始失败和修复轮分别保存，不把历史失败重写为通过。

BEGIN 的 configuration、cleanup、activation 使用各自故障阶段；发生在新阶段创建前的取消/到期按原异常和token分类，不能使用已完成的configuration invocation替代。FailureInfo.OperationOutcome描述失败子阶段是否发送；BEGIN早先已发送时，即便activation为NotSent，TransactionOutcome仍可为OutcomeUnknown且连接不可复用，不能据此建议重试。CommitUnknown保留确实已知的ServerErrorNumber；未获服务器码时保持null。当前review修复验收见 [R2 review](../implementation/reports/R2-review.md)。
